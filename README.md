# RelayHub · 中转站推广收益台

把接了推广的中转站（new-api / one-api 系）聚合到一个看板：余额、邀请奖励、累计收益统一查看，
邀请奖励一键转余额，定时自动同步，站点失联/异常有状态提示。单二进制，零第三方依赖，数据全在本机。

## 运行

```
relay-hub.exe                        # 默认 127.0.0.1:8077，数据目录 ./data
relay-hub.exe -addr 0.0.0.0:8077 -data D:/relayhub-data
```

打开 `http://127.0.0.1:8077`，首次访问设置主密码（≥8 位），之后每次重启进程需要重新解锁。

## 添加站点

两种方式接入一个站点：

- **账号密码自动获取（推荐）**：填站点地址 + 登录账号密码 → 点「自动获取令牌」。工具会登录站点、
  调用「生成令牌」接口（`GET /api/user/token`）并回填令牌与用户 ID。密码只在本机内存中使用一次，
  不保存、不写日志。注意：生成是「重新生成」语义，站点上已有的旧令牌会失效；
  启用了 Turnstile 人机验证的站会提示改用手动方式。
- **手动粘贴令牌**：到站点网页控制台 → 个人设置 → 生成「系统访问令牌」，连同数字用户 ID 一起填入。

两种方式都支持保存前「测试连接」直接回显站名、余额与邀请奖励。

## 安全设计

- 访问令牌 AES-256-GCM 加密落盘，密钥由主密码 PBKDF2（60 万次迭代）派生，只存在于进程内存
- 自动获取令牌时输入的账号密码只在请求期间存在于内存，不落盘、不写日志，用完即清
- 数据文件中不含明文令牌；API 任何响应都不返回令牌
- 锁定后所有数据接口返回 423；「锁定」按钮立即使密钥失效
- 只读轮询默认 30 分钟一次（可在设置中调，最低 5 分钟），对站方友好

## 功能

- **看板**：统计行（余额/奖励/累计收益/站点健康）+ 累计推广收益趋势曲线 + 每站迷你趋势
- **站点卡片**：余额、邀请奖励、累计收益、邀请人数、同步状态与错误详情（含连续失败次数）
- **站点类型**：`自动`（new-api / one-api / one-hub / Veloera 系，令牌接入）与 `手动记录`
  （不接 API 的魔改站，美元录入、改完即记快照）
- **操作**：单站同步、全部同步、邀请奖励一键转余额（`/api/user/aff_transfer`）、编辑、删除
- **提现台账**：登记每笔现金提现（站点/金额/渠道/申请时间），跟踪 待到账 → 已到账/失败，
  汇总待到账与已到账金额
- **快照历史**：每站保留最近 500 条（`GET /api/sites/{id}/history`），趋势图基于此重采样
  （`GET /api/trend?days=30`）

## 一键申请提现

站点卡片 →「申请提现」：金额自动预填站点可用余额，提交后自动登记台账（待到账）并打开站点提现页。

- new-api 原版**没有提现功能**（提现均为各站魔改或人工工单），所以默认行为是「登记台账 + 跳转提现页」
- 站点编辑里可配置「提现页 URL」（默认 `{base}/console/wallet`）适配任意站
- **实验性**：个别魔改站有自定义提现接口，配置「提现接口路径」后（如 `/api/user/withdraw`），
  RelayHub 会直接 POST `{amount}`（美元，带鉴权头）向站方提交申请，站方响应原样展示；成功才落台账

## Telegram 通知

设置 → Telegram 通知：

1. 在 Telegram 里找 **@BotFather** → `/newbot` 创建机器人，拿到 Bot Token 填入
2. **给你的 Bot 发送任意一条消息**，然后点「自动获取 Chat ID」
3. 点「发送测试消息」确认收到，保存即可

两类通知：

- **进账提醒**：某站累计推广收益或邀请人数增长时推送（含变化明细与当前余额/待转奖励）
- **跑路预警**：站点连续同步失败达到阈值（默认 3 次，可调）时推送一次，不重复轰炸；恢复同步后再推一条「站点恢复」

网络说明：直连 `api.telegram.org` 不通时，可填代理（`socks5://` / `http://`）；或使用自建 Bot API
地址（高级选项）。通知发送失败只记日志，不影响同步与看板。

## 已知边界

- 仅适配 new-api 系（含 one-api / one-hub / Veloera 大部分分叉）；个别魔改站接口不同步时会显示错误详情，
  可先停用该站
- 换算统一用「设置 → quota per unit」（默认 500000 = $1），以人民币结算的站目前只能近似展示
- 「现金提现」多为站方人工打款，本工具负责提醒与跳转，不代提现

## 构建

Go 1.24+，纯标准库：

```
go build -o relay-hub.exe .
```

## 浏览器插件（独立运行）

`extension/` 是一个 Manifest V3 插件：令牌与快照只存浏览器本机（chrome.storage），后台定时轮询，
不依赖本机 RelayHub 服务——这也是 SaaS 化「轮询下沉用户侧」的地基。

加载方式：`chrome://extensions` → 开发者模式 → 「加载已解压的扩展程序」→ 选择 `extension/` 目录。
添加站点时会按站点申请访问权限（`optional_host_permissions`，逐站授权，不要求全网权限）。

## 数据备份与迁移

设置 → 数据备份：导出 / 导入全部数据（站点、历史、提现台账、设置）。
导出文件中的令牌是密文，需主密码才能解密——**迁移到新机器后用「导出时的主密码」解锁即可无缝接管**。
